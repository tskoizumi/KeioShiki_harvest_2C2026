# ナレーションの台本（読み上げ用）

1行を1つのファイルに録音します。ファイル名は左の番号にしてください（例：`c01.m4a`）。
番号は動画の流れの順です。間は動画のほうで合わせるので、自分の読みやすい速さで大丈夫です。

## 録り方

- iPhone の「ボイスメモ」、Android の「レコーダー」で OK（m4a / mp3 / wav どれでも）
- 静かな部屋で、口からスマホまで 20cm くらい。服や布団の多い部屋だと響きにくい
- 1行ごとに、読む前と後に1秒ずつ黙る（前後の無音は自動で切ります）
- 言い間違えたら、その行だけ録り直せばいい
- 「、」は短く区切る。語尾ははっきり
- 全部そろわなくても大丈夫。録っていない行は、今の合成音声のまま残ります

できたら、ファイルをまとめてチャットに送ってください（zip でも、1つずつでも）。
声は公開リポジトリには入れません。
